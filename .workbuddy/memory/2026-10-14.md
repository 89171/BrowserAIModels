## 环境坑（重要，省时间）

- **Next dev 必须用 `http://localhost:<port>` 访问，不能用 `127.0.0.1`。**
  Next 16 默认拦截跨源 dev 资源（`/_next/hmr`），从 `127.0.0.1` 打开会看到页面渲染正常但
  **点击完全无反应**（hydration 未完成），极易误判成「代码 bug」。生产 `next start` 无此限制。
  如需保留 127.0.0.1，可在 `next.config.mjs` 加 `allowedDevOrigins: ['127.0.0.1']`。
- **BSD grep 不支持 `\|` 交替**，`grep -n "a\|b"` 会静默返回空。必须用 `grep -nE "a|b"`。
- agent-browser 的 ref（`@e17`）在页面重渲染/切换语言后会失效，`click` 仍报 `✓ Done` 但不生效；
  改用 `agent-browser find text "<唯一文本>" click` 更稳。
- 模型切换器有两处外观相似的按钮列表，**右侧「模型信息」面板下的「全部模型」才是真正生效的切换器**。
- agent-browser 有 `console` / `errors` 命令，可直接看页面告警（比翻 dev 日志快）：
  `agent-browser console | tail -20`。真实推理回退会打印
  `[AI-Demos] real inference failed, falling back to the simulator {message: ...}`。
- HF 带宽极不稳定：同一文件 curl 实测在 **190 KB/s ↔ 150 B/s** 之间反复。
  大模型（opus-mt 108MB / whisper-base 73MB / CLIP 146MB / t5-small 75MB）常因此跑不完，
  优先挑 5 MB 以内的小模型做端到端验证。
