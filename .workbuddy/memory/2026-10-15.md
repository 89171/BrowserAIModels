### 两个容易踩的坑
- **`max-w-prose` 在 Tailwind v4 归 `--max-width-*` 命名空间**，不是 `--container-prose`。
  写错的话仍然编译成默认 65ch。正确写法：`@theme { --max-width-prose: 70ch; }`。

  `export const dynamic = 'force-static'`（`setRequestLocale(locale)` 仍保留，负责喂对 locale 的 messages）。
  改完 88 个页面全部恢复 `●` SSG。
- 排查手法：`export const dynamic = 'error'` 会直接报出是哪次 `headers()` 调用让页面无法静态化，比猜快。
